# FedRAMP Cloud Compliance Skill

[![CI](https://github.com/DustyStudy/fedramp-cloud-compliance-skill/actions/workflows/ci.yml/badge.svg)](https://github.com/DustyStudy/fedramp-cloud-compliance-skill/actions/workflows/ci.yml)
[![License: Apache 2.0](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](./LICENSE)

An [Agent Skill](https://docs.claude.com/en/docs/agents-and-tools/agent-skills/overview) that helps
Claude Code and other skill-aware agents do FedRAMP work on **AWS, Azure, and Google Cloud**. It is
built on the **FedRAMP Consolidated Rules for 2026**, covering both 20x and Rev5.

It covers:

- **Control and KSI mapping to cloud services:** NIST SP 800-53 Rev5 controls and 20x Key Security
  Indicators mapped to native services, what the cloud provider covers, and what the customer
  still has to do.
- **Terraform / IaC review:** a FedRAMP-oriented checklist whose findings cite control, KSI, and
  rule IDs.
- **Documentation:** Security Decision Record entries, the Certification Package Overview, legacy
  Rev5 SSP narratives, CRMs, and vulnerability, incident, and significant-change reports.
- **The certification process:** 20x vs Rev5, Class A–D, Program vs Agency paths, timelines,
  ConMon, and SCN.

## Install

```bash
# Claude Code, global (~/.claude/skills/)
npx -y skills add DustyStudy/fedramp-cloud-compliance-skill --skill fedramp-cloud-compliance --agent claude-code --global
```

Without `npx` (manual install):

```bash
git clone https://github.com/DustyStudy/fedramp-cloud-compliance-skill.git
mkdir -p ~/.claude/skills
cp -r fedramp-cloud-compliance-skill/skills/fedramp-cloud-compliance ~/.claude/skills/
# or keep it updatable with a symlink (on Windows, use a directory junction: mklink /J):
# ln -s "$PWD/fedramp-cloud-compliance-skill/skills/fedramp-cloud-compliance" ~/.claude/skills/
```

For a single project, use `.claude/skills/` in that project instead of `~/.claude/skills/`.
The skill works offline from its bundled `references/generated/` snapshot. Live lookups
via `scripts/fedramp.py` need network access to raw.githubusercontent.com.

Then ask things like:

- "Which Azure services and settings support KSI-IAM-APM and IA-2(1)?"
- "Review this Terraform for FedRAMP Class C issues."
- "Draft SDR entries for the VDR ruleset for our GKE-based service."
- "How long do we have to send an initial incident report for a PAIN 4 incident at Class D?"

## Where the facts come from

| Content | Source | How it stays current |
|---|---|---|
| `references/generated/rules.md`, `ksi.md`, `definitions.md` | [`FedRAMP/rules`](https://github.com/FedRAMP/rules) `fedramp-consolidated-rules.json` | Generated by `scripts/fedramp.py build`; weekly workflow opens a PR on upstream changes |
| `references/generated/rev5-baselines.md` | [`FedRAMP/2026-markdown`](https://github.com/FedRAMP/2026-markdown) control pages (NIST SP 800-53 Rev5 OSCAL + FedRAMP Class B/C/D baselines) | Same |
| `references/program-2026.md` | Hand-written summary of the above, citing rule IDs | CI checks every cited ID still exists |
| `references/{aws,azure,gcp}.md`, `terraform-checks.md`, `documentation.md` | Hand-written. Identifiers (Azure Policy initiative IDs, AWS conformance pack names, GCP Assured Workloads regimes) checked against provider sources on 2026-09-23 | Review when providers change; each file links the live services-in-scope list |

`scripts/fedramp.py` has no dependencies beyond the Python 3.9+ standard library:

```
python skills/fedramp-cloud-compliance/scripts/fedramp.py lookup KSI-IAM-APM VDR-TFR-PVR "AC-2(1)"
python skills/fedramp-cloud-compliance/scripts/fedramp.py search "trust center"
python skills/fedramp-cloud-compliance/scripts/fedramp.py baseline d SC
python skills/fedramp-cloud-compliance/scripts/fedramp.py build   # regenerate references/generated/
python skills/fedramp-cloud-compliance/scripts/fedramp.py check   # verify cited IDs + links
```

## ⚠️ Disclaimer

This skill supports the *implementation and documentation* of security requirements. It is
**not** a FedRAMP certification and does not replace FedRAMP review, an agency sponsor, or an
independent assessment by a FedRAMP Recognized assessor. Cloud-provider service authorizations
change often, so always confirm against each provider's live FedRAMP services-in-scope list and
the rules at https://www.fedramp.gov/2026/. Not affiliated with or endorsed by GSA, FedRAMP,
AWS, Microsoft, or Google.
